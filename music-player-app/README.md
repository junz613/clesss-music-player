# music-player-app

播放器应用代码目录。

当前进度：

- `server` 已完成 Express + TypeScript + Prisma + MySQL 基础服务。
- 已支持健康检查、歌曲列表、歌曲搜索、本地歌曲扫描入库和 Range 音频流。
- `client` 仍是占位目录，下一步进入 Vue 3 + Vite 前端骨架搭建。

目录结构：

```text
client/   前端 Vue 3 + Vite 项目
server/   后端 Express + TypeScript + Prisma 项目
docs/     接口、数据库和部署补充文档
```
